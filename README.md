# 🧩 Maze Generator and Solver (Python)

A Python project that **generates random mazes** using different algorithms and **solves them automatically** using search techniques.

This repository demonstrates maze creation, pathfinding logic, and visual animation to help users understand how maze generation and solving algorithms work in action.

---

## 🧠 Features

✔ Generate random mazes  
✔ Multiple generation algorithms  
✔ Automatic maze solving  
✔ Visualization of maze and solution  
✔ Clean and interactive Python implementation

---

## 🛠 Technologies Used

- Python 3.x
- Optional: `pygame` or `matplotlib` (depending on how the visuals are implemented)
- Standard Python libraries

---

## 💡 How It Works

1. **Maze Generation**
   - Uses randomized algorithms (e.g., Depth-First Search, Recursive Backtracking) to build a maze.
   - Each run creates a unique, solvable structure.

2. **Maze Solving**
   - Uses search algorithms (e.g., BFS, DFS, A*) to find a path from start to finish.
   - Displays the solution path clearly on the maze grid.
